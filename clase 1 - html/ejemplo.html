Desarrollo Web

HTML

HTML es un lenguaje de marcado de texto, el cual permite definir la estructura de un sitio web. Nosotros utilizaremos HTML5.

CSS

CSS es el encargado de aplicar forma a la estructura. Gracias a este podemos cambiar colores, tipos de letra, tamaños, etc. Usaremos CSS3.

Javascript

JS es un lenguaje de programación. Se concibió para funcionar del lado del cliente, pero actualmente hay maneras de usarlo también en el servidor.
